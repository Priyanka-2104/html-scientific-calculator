HTML Scientific Calculator

Type an expression and press Evaluate. Trig functions follow the selected unit (Radians or Degrees); use sin_deg(x) for explicit degrees. Supported helpers: ln(x) (natural log), log(x) (natural log), log10(x), pow(a,b) or a^b, sqrt(x), factorial(n), and pi.
